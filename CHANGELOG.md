# Changelog

All notable changes to `pb-sqlite` are documented here.

## 1.0.0 - 2026-11-09

- Browser-first SQLite API with OPFS persistence and Web Worker execution.
- Parameterized SQL, typed errors, transactions, migrations, and lifecycle controls.
- Multi-tab coordination with Web Locks and BroadcastChannel.
- ESM/CJS distribution with TypeScript declarations and bundled SQLite WASM.
- Vite, React, Next.js, English, and Portuguese documentation.

## 0.2.0 - 2026-11-09

- Forked and professionalized from lona-q.
- Established the `pb-sqlite` package workspace and reproducible CI foundation.
