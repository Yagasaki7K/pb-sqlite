# pbdb

Polar Bear Database is a browser SQLite library built around OPFS, Web Workers, React hooks, and multi-tab coordination.

> Fork of [lona-q](https://github.com/Lona-up/lona-q) — professionalized with worker threading, robust migrations, Web Locks multi-tab support, and i18n documentation.

See the repository README and documentation site for the API and browser support matrix.
