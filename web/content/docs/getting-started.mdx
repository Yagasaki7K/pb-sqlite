# Getting started

## Install

```bash
bun install pb-sqlite
# npm install pb-sqlite also works
```

## Create a database

```ts
import { createDB } from 'pb-sqlite';

const db = await createDB('tasks');
await db.run(`CREATE TABLE IF NOT EXISTS tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  done INTEGER NOT NULL DEFAULT 0
)`);
await db.run('INSERT INTO tasks (title) VALUES (?)', ['Read the docs']);
```

The name is the stable identity of the local database. Use a different name for independent datasets. Opening the same name in another tab connects that tab to the same local database.

## Read data with types

```ts
type Task = { id: number; title: string; done: number };

const tasks = await db.query<Task>(
  'SELECT id, title, done FROM tasks WHERE done = ? ORDER BY id DESC', [0]
);
const first = await db.getOne<Task>('SELECT * FROM tasks WHERE id = ?', [1]);
```

`query` always returns an array. `getOne` returns the first row or `null`. Use SQL parameters for user input.

## Close when the app is done

```ts
await db.close();
```

In a long-lived browser app, keep one database instance for the application lifetime. In React, let `PbdbProvider` manage it.

## Browser-only boundary

`createDB` requires OPFS and a browser Worker. In Next.js, call it from a Client Component or inside an effect. Do not call it during build, in a Server Component, or in a Node.js script.
