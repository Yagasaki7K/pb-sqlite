# API reference

## `createDB(name, options?)`

Opens a browser database and returns a `PbdbDatabase`.

```ts
const db = await createDB('catalog', {
  storage: 'opfs',
  debug: false,
  onError: (error) => console.error(error),
});
```

## SQL methods

```ts
await db.run('UPDATE products SET stock = stock - ? WHERE id = ?', [1, productId]);
const products = await db.query<Product>('SELECT * FROM products WHERE stock > ?', [0]);
const product = await db.getOne<Product>('SELECT * FROM products WHERE id = ?', [productId]);
```

`run` is for statements without a row result. `query` returns `T[]`; `getOne` returns `T | null`.

## Transactions

```ts
await db.transaction(async (tx) => {
  await tx.run('INSERT INTO orders (id) VALUES (?)', [orderId]);
  await tx.run('INSERT INTO order_items (order_id, sku) VALUES (?, ?)', [orderId, sku]);
});
```

The transaction commits if the callback completes and rolls back if it throws. The transaction object exposes `run`, `query`, and `getOne`.

## Lifecycle and data movement

- `isReady`, `close()`, and `onTableChange(listener)` manage lifecycle and observation.
- `migrate(migrations?)` and `rollback(targetVersion, migrations?)` manage schema changes.
- `export()` / `import(payload)` use a portable typed payload.
- `exportSQLite()` / `importSQLite(data)` use a native SQLite image.
- `invalidate(tag)` / `invalidateAll()` notify reactive consumers.

The package exports typed errors including `PbdbNotReadyError`, `PbdbTimeoutError`, `PbdbQueryError`, `PbdbStorageError`, `MigrationChecksumMismatchError`, `OPFSUnavailableError`, `QuotaExceededError`, and `LeaderElectionError`.
