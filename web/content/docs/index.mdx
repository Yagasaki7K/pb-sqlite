# Documentation

pb-sqlite is a browser-only SQLite runtime for local-first web applications.

Start with [Getting started](/docs/getting-started), then learn the [architecture](/docs/concepts), choose a [use case](/docs/use-cases), or jump to the [API reference](/docs/api).

## The mental model

```text
UI -> pb-sqlite API -> Worker -> SQLite file in OPFS
             ^             |
             +-- tab coordination --+
```

The package never uploads data, chooses a server, or invents a synchronization protocol for you.
