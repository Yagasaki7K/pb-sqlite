# Migrations

Migrations make schema changes explicit, ordered, and reviewable.

```ts
import type { Migration } from 'pb-sqlite';

const migrations: Migration[] = [{
  version: 1,
  name: 'create notes',
  up: 'CREATE TABLE notes (id INTEGER PRIMARY KEY, body TEXT NOT NULL)',
  down: 'DROP TABLE notes',
  checksum: '',
}];

await db.migrate(migrations);
```

Migrations are sorted by version and recorded in `_pbdb_migrations`. The checksum is derived from version, name, and `up` SQL when empty. Once applied, changing a migration is an error; add a new version instead.

`rollback(targetVersion, migrations)` runs declared `down` SQL in reverse order. A migration without `down` cannot be rolled back safely.
