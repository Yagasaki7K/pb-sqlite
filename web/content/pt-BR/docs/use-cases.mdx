# Casos de uso

- **Formulários offline:** salve rascunhos, inspeções e checklists antes de sincronizar.
- **Dados privados:** mantenha preferências, workspaces e rascunhos no dispositivo por padrão.
- **Busca rápida:** importe catálogos ou datasets e use índices SQLite localmente.
- **Aplicações instaláveis:** combine o banco local com um service worker para o app shell.
- **Cache local com sincronização explícita:** mantenha um read model local e envie mudanças pela API da sua aplicação.

O pb-sqlite não substitui backend, autorização, criptografia ou sincronização entre dispositivos.
