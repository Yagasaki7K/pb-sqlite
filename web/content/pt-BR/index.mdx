# SQLite local-first para a web

O `pb-sqlite` mantém dados localmente no navegador usando OPFS, executa SQLite em um Web Worker e coordena múltiplas abas.

```bash
bun install pb-sqlite
```

Comece pelo [guia de primeiros passos](/pt-BR/docs/getting-started) ou consulte a [referência da API](/pt-BR/docs/api).
